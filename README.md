# 💳 E-Wallet System (Simplified Digital Wallet)

A web-based e-wallet application that mimics the core functionalities of platforms like MoMo or modern online banking. This project was developed as a collaborative assignment, emphasizing structured data models, maintainable code, and a clear separation of concerns.

## 🌟 Key Features

### 👤 User Role (Customer)
*   **Registration & Verification:** Users can register and must wait for Administrator approval to access features.
*   **Wallet Operations:** Essential financial transactions (Transfer, Deposit, Withdraw - *tùy biến theo tính năng bạn đã làm*).
*   **Transaction History:** Securely maintains and displays consistent transactional data.

### 🛡️ Administrator Role
*   **KYC Management:** Single predefined account responsible for reviewing and approving user registrations.
*   **System Oversight:** Monitoring overall system activity and user status.

## 🛠️ Tech Stack
*   **Backend:** PHP (Strictly required)
*   **Database:** MySQL
*   **Frontend:** HTML5, CSS3, JavaScript (Bootstrap/jQuery supported)
*   **Tools:** Composer, Git/GitHub
